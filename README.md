# Chef Menu Manager - Part 3

An Android app for a chef to manage their restaurant menu.

## Features
- Add new menu items with name, description, price and course
- Edit existing menu items
- Delete menu items
- Filter menu by course: Starters, Mains, Desserts
- View all menu items in a list
- Calculate and display the average price per course

## How to Run
1. Open the project in Android Studio
2. Run on an emulator or physical device (Pixel 6a or higher)
3. Add items using the form and use the filter buttons to view by course

## Tech Used
- Kotlin
- Jetpack Compose
- Android Studio
